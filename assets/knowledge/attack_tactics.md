# MITRE ATT&CK 攻击技战术知识库

## 攻击链阶段（Kill Chain / ATT&CK）

1. **侦察 Reconnaissance**：端口扫描、服务发现（T1046, T1595）
2. **初始访问 Initial Access**：暴力破解（T1110）、钓鱼（T1566）、漏洞利用（T1190）
3. **执行 Execution**：恶意命令执行、脚本运行（T1059）
4. **持久化 Persistence**：后门账户、计划任务（T1053, T1136）
5. **横向移动 Lateral Movement**：远程服务滥用 SMB/RDP/SSH（T1021）
6. **收集 Collection**：敏感数据打包（T1005）
7. **命令与控制 C2**：心跳通信、隧道（T1071, T1090）
8. **数据外传 Exfiltration**：加密通道外传、DNS 隧道（T1041, T1048）
9. **影响 Impact**：勒索、数据破坏（T1486）

## 证据要求与置信度对照

| 阶段 | 最低证据要求 | 无更深层证据时的置信度 |
| --- | --- | --- |
| 扫描 | 单源多端口 SYN | 0.8（可较确定） |
| 暴力破解 | 同源目高频连接 | 0.75 |
| C2 心跳 | 5+ 次等间隔通信 | 0.7（疑似） |
| 数据外传 | 大流量上行 | 0.6（需内容确认） |
| 攻击成功 | 载荷内容/终端日志 | < 0.5（仅 PCAP 不可确认） |

## 关联攻击链的规则

- 只能基于现有证据 ID 关联，每个阶段至少有一条证据支撑
- 缺失阶段要明确标注"缺失证据"，例如：发现扫描 + C2 心跳，但没有发现初始访问证据时，输出"初始访问方式未知"
- 不确定性的来源要写明：无终端进程日志、加密流量不可读、时间窗口不完整等

## 处置动作映射

- 扫描行为 → 建议封禁源 IP（L2，需授权）
- 暴力破解 → 建议封禁 + 加强认证策略（L2）
- C2 心跳 → 建议 EDR 隔离受感染主机 + 封禁 C2 地址（L2）
- 数据外传 → 建议阻断连接 + DLP 审查（L2）
- 所有 L2 动作必须先请求用户授权，附目标、范围、原因、回滚方式
