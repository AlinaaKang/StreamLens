# StreamLens 明鉴 平台总结报告

---

## 1 项目成果概述

本项目交付了一套面向大模型应用入口的 **Prompt 安全检测平台（StreamLens 明鉴）**，围绕"语义安全 × Token 分布"双证据融合构建，实现：

1. **三路独立取证引擎**：规则标记层（已知越权模式）+ Entropy-CPD 分布层（token 熵轨迹 + CUSUM 在线变点检测，纯 CPU 毫秒级）+ 语义扫描层（大模型意图判定），三路独立取证、互不覆盖；
2. **固定融合策略**：处置动作（放行 / 人工复核 / 拦截）来自固定融合表，拦截必须有语义佐证，纯统计异常只转人工复核——不确定时不阻断；
3. **全程可审计**：结构化证据链（real=真实检测 / derived=数学推导）、步骤化决策轨迹（不含隐藏思维链）、审计事件流水，"疑似发现 → 待授权复核"口径全程一致；
4. **对抗验证闭环**：红蓝攻防演练以真实检测引擎为靶场；曲线侦探挑战将 CPD 检测过程转化为可交互、可归因（反事实复检）的关卡教学；
5. **生产级工程细节**：分布层四重防误报闸门、流式输出切页续显、刷新后会话/证据/工具日志三层恢复、任务化证据归档与正式报告生成。

## 2 主要创新点

1. **把"分布异常"变成可解释的第二证据**：不依赖本地大模型，用字符级熵代理 + CUSUM 在线变点检测捕捉注入拼接、载荷插入、高熵编码留下的分布"台阶"，毫秒级、可解释、可回放（Token 风险轨道逐 token 可视化）；
2. **反事实归因**：对每个异常起点自动执行"截断重检"，用分布分数变化（risk_reduced / unchanged）验证归因是否成立，证据冲突时如实标注"需人工研判"，不伪造结论；
3. **双证据交互的语义锚定**：语义判定异常时将分布层观察级候选升级为 alarm 级证据，交叉确认提升对抗样本检出；
4. **误报治理方法论**：以"强度校验（|z|≥2.0）+ 持续偏移校验 + 短文本置信折减"三重闸门分离"口语短文的自然波动"与"真实突变"，真实误报案例（日常科普/口语文本）修复后放行、真攻击与优化后缀攻击全部保留拦截，回归零损失；
5. **检测能力游戏化验证**：红蓝对抗 + 曲线侦探让"检测为什么对/为什么错"对评委与用户可见、可操作。

## 4 演示流程指引（配合 5 分钟演示视频）

1. **开场（30s）**：平台定位——"给大模型入口装一双看得见的眼睛"；
2. **对话检测（60s）**：粘贴注入攻击文本，流式输出检测结论 + 证据链，展示切换页面再返回的续显能力；
3. **安全分析面板（90s）**：检测正常科普文本（放行、观察级波动展示）→ 检测注入文本（拦截）；重点演示 **Token 风险轨道**（竖虚线吸附、T 序号、候选高亮、点击选起点）与**反事实归因**；
4. **红蓝攻防（60s）**：红队提交 payload 被真实引擎拦截；蓝队对样本研判计分，展示回合详情；
5. **曲线侦探（45s）**：选择 GCG 关卡，观察 CPD 曲线定位异常起点，系统复检归因；
6. **审计与总结（15s）**：审计流水与"待授权复核"口径收尾。

## 5 展望

- 多语义模型交叉投票，进一步压降语义层误报；
- 扩充多语种注入、多轮上下文攻击样本族；
- 熵代理升级：可选接入本地轻量 LM 提升 token 熵粒度；
- 处置编排：与网关/下游执行链联动，将"待授权复核"闭环为可配置的处置工作流。

## 附：合规声明（要点）

- 待检文本仅在平台内完成检测与证据归档；语义层调用内置模型服务，仅传输完成检测所必需的文本内容，不用于模型训练；
- 证据与审计全程本地存储，支持回溯与导出；
- 检测组件不越权执行处置：疑似异常一律"待授权复核"；
- 项目代码与文档为参赛团队原创，第三方开源组件见仓库依赖清单。
