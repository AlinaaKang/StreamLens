# StreamLens 明鉴 五分钟演示脚本与分镜

## 0:00 至 0:30 开场

画面：打开 Web 工作台首页。

台词：StreamLens 明鉴是一名安全调查智能体。它不只给风险标签，而是读取案件证据，自动检测、解释、修复、复检并生成报告。

## 0:30 至 1:30 Prompt 对话检测

画面：在安全对话中输入一条合成 Prompt 注入样本。

台词：我直接用自然语言提出检测请求。Agent 先说明计划，再调用三路检测工具。结果中分别展示规则证据、Token 分布证据和语义证据，并标注来源和限制。

操作重点：展示流式回答、工具状态、风险等级、证据编号和下一步建议。

## 1:30 至 2:20 误报和反事实归因

画面：切换一条正常科普文本，再打开 Token 风险轨道。

台词：正常文本的统计波动不会被直接定罪。四重闸门会降低短文本和弱突变的误报。对有定位的样本，系统还会截断重检，验证风险是否确实来自异常片段。

操作重点：展示放行结果、候选位置和反事实结论。

## 2:20 至 3:20 Prompt 红蓝攻防

画面：进入红蓝攻防实验，提交合成对抗变体。

台词：红队提交对抗样本，蓝队使用同一套真实检测管线判断是否拦截。系统展示命中依据、规避结果和回合计分，不使用虚假的检测回执。

## 3:20 至 4:20 PCAP 调查

画面：上传 `assets/test_data` 中的教学 PCAP。

台词：PCAP 侧先做文件预检，再进行规则、行为和融合三路分析。证据会显示协议、方向、时间、地址和 Packet 位置。加密流量的周期性只能作为弱证据，最终需要人工复核。

操作重点：打开一个 PCAP 证据详情，并展示攻击链关联入口。

## 4:20 至 4:50 报告和审计

画面：查看案件审计记录并点击生成报告。

台词：调查过程、证据来源和处置边界都会归档到案件中。报告只引用真实执行记录；封禁和隔离等高影响动作仍需要授权。

## 4:50 至 5:00 收尾

台词：这个系统把大模型的对话能力和安全引擎的可审计能力结合起来，完成从发现、解释到复检和报告的安全调查闭环。
