## 01 背景：两类"流"上的威胁，同一套检测哲学

**威胁早已不只在文本里**

- Prompt 域：注入、越权指令、角色扮演绕过、敏感信息诱导泄露——攻击藏在 **Token 流** 的异常里
- 流量域：C2 心跳、横向扫描、数据外传——攻击藏在 **数据包流** 的节律里

**现有方案的两难**

| 路线 | 痛点 |
|---|---|
| 纯规则引擎 | 维护成本高、易被改写绕过 |
| 纯语义模型 | 黑盒结论：无法解释、无法审计、误报无从申辩 |
| 单证据定罪 | 误报率高，生产无法立足 |

**核心诉求：既拦得住，也说得出为什么**

---

## 02 核心理念：双证据独立取证

**语义层说"是什么"，分布层说"变没变"，融合表说了算**

- **独立取证**：语义判定 与 统计分布检测 互不覆盖、互不背书
- **固定融合**：处置动作来自固定策略表，同一输入永远同一处置，可回归、可复现
- **全程可审计**：结构化证据链 + 步骤化决策轨迹，不含隐藏思维链
- **职责分离**：检测不越权处置——疑似异常一律"待授权复核"

---

## 03 系统架构：一套方法，两个检测域

**前端工作台（6 大工作区）**

- 对话式检测 · Prompt 安全分析面板 · PCAP 专业工作区 · 红蓝攻防演练 · 曲线侦探挑战 · 审计中心

**服务与引擎（FastAPI）**

- Prompt 域：规则标记层 → Entropy-CPD 分布层 → 语义扫描层 → 固定融合表
- 流量域：会话重组 → 规则+行为融合检测 → 风险分级 → 待授权复核
- case_store 证据归档：任务 / 消息 / 证据 / 审计事件 / 知识库

---

## 04 Prompt 域：三路检测引擎

**① 规则标记层**：已知越权短语快速通道，命中仅作证据、不单独定罪

**② Entropy-CPD 分布层（自研核心）**

- 字符级熵代理 + NLL 轨迹 → 标准化 z 值（up=载荷突变 / down=模板化片段）
- CUSUM 在线变点检测：累计统计量过门限报警 + 强突变直报通道
- 纯 CPU 毫秒级，无需 GPU

**③ 语义扫描层**：大模型意图三档判定（safe / controversial / unsafe），real 证据 + 置信度

---

## 05 Entropy-CPD：把分布异常变成看得见的证据

**注入拼接、载荷插入、高熵编码，都会在熵轨迹上留下"台阶"**

- Token 风险轨道可视化：逐 token z 值曲线 + 累计统计线
- 鼠标竖虚线吸附 token、顶端 T 序号、候选点高亮、点击选异常起点
- 反事实归因：截断至异常起点重算 CPD，风险下降=归因成立；冲突=如实标注"需人工研判"
- 语义锚定升级：语义异常时观察级候选升级为 alarm 证据，双证据交叉确认

---

## 06 流量域：PCAP 会话级融合审计

**344 包真实形态样本，5 类攻击场景一站式检测**

- 会话重组：按五元组聚合双向流，恢复时序上下文
- 规则+行为融合：明文特征（口令/密钥/命令）与行为节律（扫描/C2 心跳/批量外传）交叉确认
- 场景库：暴力破解 · 端口扫描 · C2 外联回连 · 数据外传 · 隧道外带
- 审计口径：有发现→"待授权复核"，未发现→"放行"，杜绝"报告疑似、审计放行"

---

## 07 防误报：四重闸门 + 真实案例

| 闸门 | 规则 | 拦截的误报形态 |
|---|---|---|
| 短序列不报警 | token < 10 不判定 | 自然波动当突变 |
| 持续偏移校验 | 报警后 6 token 均值 ≥ 0.3 | 零星高 NLL 迅速回落 |
| 强度校验 | 报警点 \|z\| < 2.0 拒绝报警 | 口语短文持续小幅偏移（\|z\|≈1.3~1.7 vs 真突变≈4.0） |
| 短文本置信折减 | token < 30 置信上限 0.45 | 短序列无回落窗口可校验 |

**真实案例**："光合作用是植物、藻类……请给小学生简单讲解"

- 修复前：高风险 · 拦截 ❌ → 修复后：**放行 · 风险分 0** ✅
- 同一回归中 GCG 优化后缀与注入窃取样本依旧拦截，29 样本零损失

## 08 固定融合策略表

| 语义判定 | CPD 信号 | 风险级别 | 处置动作 |
|---|---|---|---|
| unsafe | 任意 | 高风险 | **拦截** |
| controversial | 任意 | 中风险 | 人工复核 |
| 语义服务故障 | 任意 | 网关:中 / 面板:降级放行 | fail-safe 人工复核 |
| safe | alarm 级 | 中风险 | **人工复核（不拦截）** |
| safe | 观察级/无 | 未发现 | 放行 |

**设计原则**：拦截必须有语义佐证；CPD 属间接证据不单独定罪；不确定时不阻断

---

## 09 可审计：证据链与决策轨迹

- **证据分级**：real=真实检测（语义/规则） · derived=数学推导（熵轨迹/CPD/置信）
- 每条证据：来源、状态、摘要、置信度、字符级定位、snippet、**限制说明如实披露**
- **决策轨迹五步**：语义检测 → Token 观测 → CPD 判断 → 证据融合 → 处置决策
- 审计口径全程一致："疑似发现 → 待授权复核"，无发现 → 放行，杜绝矛盾记录
- 正式报告一键导出，决策可复现可回归

## 10 功能巡礼：检测能力可操作、可对抗、可教学

**对话式检测**：粘贴即检，流式回显结论+证据；切页续显、刷新后消息/证据/工具日志完整恢复

**红蓝攻防演练**：红队 payload 过真实引擎，蓝队样本研判计分；判分口径归一化、回合详情中文化

**曲线侦探挑战**：8 大样本族（SAFE/SHIFT/AD/GCG/ADVP/ENC/CTX/EXF），看曲线、定位异常起点、反事实复检验证归因

**PCAP 专业工作区**：冻结样本一键检测、会话级证据面板、审计联动
