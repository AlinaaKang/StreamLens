PCAP 数据调查

            
批量导入数据集样本（匿名编号），两次确认授权后批量执行四类规则检测，结果按匿名 ID 展示，支持失败重试。

          

        

        
      

      

        🔐 两次确认 + 一次性授权码 · 匿名展示 · 单批上限 20
        
      

      

        

          第一步 · 选择批次规模
          
从数据集顺序选取样本并生成匿名编号（PCAP-001 起），单批上限 20 个文件。

          

            
            
          

          

        

        

          第二步 · 确认授权（两次确认）
          
先生成批次，确认批次明细与授权码后再授权执行。

        

        

          第三步 · 执行与结果
          
授权执行后，此处展示批量检测进度与匿名结果。

        

      

      
授权说明：批量检测会读取样本文件内容并运行四类规则引擎（端口扫描 / 认证暴破 / C2 心跳 / SQL 注入）。授权码为一次性凭证，消费后即失效；结果页只展示匿名编号与检测摘要，不暴露原始文件名。
